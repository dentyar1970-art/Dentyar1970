## معرفی

DENTYAR یک سامانه جامع مدیریت مطب و مراکز دندان‌پزشکی است که با هدف ساده‌سازی، یکپارچه‌سازی و هوشمندسازی فرآیندهای روزمره طراحی می‌شود.

اصل اساسی پروژه:

> هر اطلاعات فقط یک‌بار ثبت شود و در تمام بخش‌های مرتبط قابل استفاده باشد.

DENTYAR با رویکرد **Local-first، Sync-ready و Native-ready** طراحی می‌شود تا بدون وابستگی دائمی به اینترنت قابل استفاده باشد و در مراحل بعد امکان همگام‌سازی امن اطلاعات را داشته باشد.

---

## مرجع طراحی

طراحی ظاهری و تجربه کاربری DENTYAR VERSION 1 از نسخه مرجع **V59** الهام می‌گیرد؛ اما معماری و کدنویسی VERSION 1 از ابتدا بازطراحی می‌شود تا مشکلات و محدودیت‌های نسخه‌های قبلی به پروژه جدید منتقل نشود.

- پشتیبانی از تاریخ شمسی

- سیاست یکپارچه نمایش اعداد

# معماری پروژه

DENTYAR VERSION 1 بر پایه سه اصل معماری توسعه داده می‌شود:

### Local-first

اطلاعات اصلی ابتدا در دستگاه کاربر ذخیره می‌شود و عملکرد روزمره سیستم نباید به اینترنت وابسته باشد.

### Sync-ready

ساختار داده‌ها از ابتدا به‌گونه‌ای طراحی می‌شود که امکان همگام‌سازی با Firebase وجود داشته باشد.

### Native-ready

ساختار برنامه باید امکان بسته‌بندی به‌صورت Android APK و نسخه دسکتاپ را فراهم کند.
